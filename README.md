# 知序网页端

知序网页端与 Android APK 共用账号和云端数据，包含：

- AI、生物制药与洁净工艺、PostgreSQL 体系化卡片；
- 阅读进度、收藏、深度内容和 AI 追问同步；
- 网页创建一次性配对码，Android 领取可撤销设备令牌；
- JSON 与 Markdown 本地导出；
- IndexedDB 离线快照；
- D1 持久化和服务端 DeepSeek 调用。

## 安全边界

- 数据库逻辑绑定只存在于 Cloudflare Worker 运行环境。
- 数据库地址和密码不会进入浏览器代码或 APK。
- DeepSeek API Key 仅可通过托管环境变量配置。
- 数据库仅保存 Android 设备令牌的 SHA-256 哈希。
- 网页身份由托管登录验证，API 会在服务端再次检查数据归属。

## 注释约定

应用源码中的类型、常量、函数、参数、关键局部变量、数据库字段和配置均使用中文注释。第三方依赖与构建工具生成文件不属于手写业务源码。

## 数据主从关系

D1 是唯一主数据源。网页 IndexedDB 与 Android SQLite 都是可丢弃、可重建的离线缓存。冲突处理以服务端 `updatedAt` 为准，收藏使用当前状态覆盖，阅读状态与深度内容按账号和卡片唯一。
