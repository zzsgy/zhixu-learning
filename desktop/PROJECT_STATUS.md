# 知序本地知识库：项目状态

更新时间：2026-08-31

## 当前定位

知序是仅供个人使用的 Windows 本地知识库。网页服务监听 `127.0.0.1:47821`，正文、阅读记录、论文、项目研读档案、问答记录和目录结构保存在本机 SQLite；当前电脑的数据根目录是 `D:\ZhixuData\data`，视频运行目录是 `D:\ZhixuData\video-runtime`。

当前只考虑电脑端，不包含账号、多用户和远程云数据库。

## 已完成模块

- 文档库：本地文档上传、网页文章解析、文件夹分层、移动、收藏、删除、搜索。
- 阅读页：目录侧栏、阅读工作台、字体和行距调整、批注、文章内 AI 问答、悬浮返回。
- 本地文档章节阅读：Word、PDF 及其他可解析文件默认使用站内正文页；Word 优先按 H1/H2 并保留内嵌图片，PDF 优先读取文件内嵌原生书签及其物理页码，没有书签时才按“第 X 章”或 1、1.1 等正文标题回退识别。PDF 解析同时记录逐页文字坐标、多栏间隙、连续编号图例及内嵌图片数量：普通单栏页面继续使用可重排 HTML；多栏、爆炸图/编号引线、多图混排等复杂页面使用可选择、可复制的双栏 HTML 重建。正文仍是 HTML；工艺图只按图注边界局部裁剪原 PDF，完整保留叠加在底图上的矢量编号圆点、引线、图例和图注，不再把整页栅格化。图中已保留的孤立数字标号不会再次落入页尾正文。左右栏顺序、页眉和页码保持对应，扁平文本仍进入搜索与 AI 数据层但阅读页不重复显示。异常的乱序孤立书签会自动排除，表格数值和单位不再误判为目录标题。带编号题注的矢量表格仍可依据 PDF 文字坐标进行局部高清裁剪。左侧显示整本文档章节，正文单次只渲染当前章。超长章节继续按安全字数拆成 1/2、2/2，无法识别标题时按固定长度分页；顶部和底部均可切换上一章/下一章，阅读进度按整本文档保存。PDF 原版不再嵌入知序页面，而是由“↗ 新标签页查看原版”直接交给 Chrome/Edge 原生 PDF 阅读器。
- 教程导入：支持 Docsify/GitHub docs 目录识别与批量章节导入。
- 论文库：经典论文推荐、PDF/链接导入、英文原文保存、Codex 中文翻译队列。
- 资料问答：基于本地资料检索、引用核验、对话历史；当前左侧入口隐藏，代码和既有记录保留。
- 项目研读：输入公开 GitHub 仓库主页链接，按顺序采集项目元数据、README、目录树、主要贡献者、最新版本和关键配置文件，并基于这些可核验证据生成简体中文项目画像、架构、核心模块、技术栈、执行链路、优势风险、上手顺序与学习建议。即使仓库资料全部为英文，项目名、代码和文件路径以外的自然语言说明也必须使用中文；首次结果中文比例不足时自动执行结构化中文转换，仍不合格则拒绝保存。报告和关键统计保存在本机 SQLite；未配置 DeepSeek 时降级为不虚构细节的本地概览，可选 `GITHUB_TOKEN` 仅在本机服务端用于提高 GitHub API 访问额度。
- 本地运维：SQLite 备份、服务守护进程和 Windows 自启动任务。
- Windows 桌面版：通过 Electron 复用现有本机 HTTP 服务和同一份 SQLite 数据，提供品牌启动页、单实例窗口、系统托盘、中文菜单、本机健康检查和服务按需启动；外部链接交给系统浏览器，桌面网页内容保持 Node 隔离。开发版沿用现有数据配置；正式安装版把默认数据库、附件、私密环境配置和日志放在当前 Windows 用户的应用数据目录，安装包和 Git 均不包含本机知识库、密钥或运行记录。Electron Builder 可生成支持自选安装目录、桌面快捷方式和开始菜单入口的 x64 Windows 安装程序。
- 第五批第一阶段：统一后台导入任务、任务恢复与失败重试、Chrome/Edge 快速收藏扩展、一次性配对和客户端撤销。
- 浏览器验证网页收藏：普通后台抓取遇到 HTTP 403 时明确提示改用快速收藏；扩展 0.2.1 在用户主动点击后读取当前标签页 HTML，供本机服务按同一公网 URL 校验、15 MB 容量限制和正文安全清洗流程解析，兼容 Cloudflare 等只能在真实浏览器中打开的公开文章。完整 HTML 不写入持久化任务参数，扩展不读取 Cookie、密码或浏览器存储。
- 网页文章图片稳定缓存：同一图片的首次并发请求共享一次安全下载和磁盘写入，进程外缓存竞争安全复用；阅读页遇到瞬时加载失败会自动重试一次，避免新导入文章首次打开时长期显示破图。
- 文档库展示名称：本地文档和网页文章均可从列表修改名称；人工名称与原文件名、来源标题分开保存，并同步列表、搜索结果、阅读页和全文索引，后续重新解析来源时不会覆盖人工名称。
- 第五批第二阶段：图片及扫描 PDF 本地 OCR、分页正文与坐标、置信度、自动入队和阅读页重试。
- 第五批第三阶段：YouTube/哔哩哔哩视频链接、公开字幕优先提取、时间戳正文、无字幕等待确认与仅保存链接流程。
- 第五批第四阶段：无独立字幕轨时，经用户逐条确认后本地临时下载视频，完成语音转写、关键画面提取、画面 OCR 与时间轴对齐，并生成可搜索图文 PDF；任务结束自动删除临时媒体。
- 第五批第五阶段：视频入口统一生成图文 PDF 并作为正式文档进入文档库；有公开字幕时直接用于时间轴对齐，没有字幕时才本地转写。视频运行资产和临时目录迁移到 D 盘。
- 视频 PDF 精简：移除画面 OCR 文本区及逐帧 OCR 步骤，只保留关键截图、对应讲解与原视频时间戳。
- 后台任务中心精简：活动和失败任务优先，已完成任务默认只显示最近 5 条；支持状态/类型筛选、全部历史切换，并通过固定高度滚动避免页面无限向下延伸。
- 论文库状态修复：论文列表改用正文词数和全文翻译状态判断可读性，避免接口省略大段正文后误显示为“正在后台下载并解析”。
- 论文库视图：支持网格与紧凑列表切换，列表集中展示标题、作者、摘要、来源、日期、翻译状态和操作入口，并单独记住上次选择。
- 列表中文简介：英文网页文章在文档库中优先展示 Codex 已保存的中文简介；英文论文优先展示中文摘要，没有独立摘要时从已完成的中文全文提取首个正文段。尚未完成翻译的条目仅显示中文处理状态，不再在标题后直接铺出英文简介。
- 上传反馈精简：文档上传成功后改用右下角短暂通知，成功状态行自动收起且空队列不再占位；上传中和失败状态仍留在页面，便于观察和处理。
- 文件夹批量导入：导入页在 Chrome/Edge 中优先使用原生目录选择器，旧浏览器回退到 `webkitdirectory`；通过受控相对路径在知识库中建立或复用同名目录树，常见临时文件自动跳过，批次使用总进度显示，成功结果自动收起、失败文件集中保留。
- 导入查重：普通文档按规范化原标题和 SHA-256 原文件摘要查重，网页文章按最终网址、规范化原标题和正文查重；单文件重复时明确提示，文件夹批量导入静默跳过重复项并在结束后集中列出文件名和命中原因。
- 上传目录选择：单文件、多文件和文件夹批量导入均可选择系统自动识别，或在上传前指定现有知识库目录；指定目录下仍保留本机文件夹的相对层级。
- 导入中心界面：本地文档、论文、网页文章和视频统一为紧凑的 2×2 卡片布局，缩短说明、输入区和按钮高度；中窄屏自动切换单列，原有目录选择、批量上传、查重与后台任务逻辑不变。
- 文档库完整列表：文档和网页文章列表接口一次返回上限统一提升到 1000 条，避免资料总量超过默认 200 条后，文件夹卡片显示数据库完整数量、打开目录却只渲染最近一部分内容。
- 批量移动：文档库提供批量整理模式，可勾选多项文档、网页文章或统一搜索结果，再通过数据库事务一次移动到目标目录。
- 批量删除：批量整理模式可永久删除当前勾选的多项内容；执行前显示数量和标题摘要并再次确认，服务端通过单一事务清理正文、索引及关联记录，随后删除对应原始附件，任一目标无效时整批拒绝。
- 文件夹移动：文件夹卡片可把整个目录树移动到另一目录下或知识库根目录；服务端拒绝移动到自身、后代目录和同级同名目录，原有内容归属与累计数量随目录树完整保留。
- 移动目录选择器：单项、批量内容和整个文件夹共用可逐级折叠的目录树，默认只展开来源路径，支持按名称或完整路径搜索、全部折叠，并可在弹窗内直接新建一级目录或选中目录的子文件夹。
- 文章翻译自动化：英文文章加入队列后由本机 Codex 分段翻译；解析器会把旧博客误用的非 SVG `<image>` 规范化为标准图片，原文图片再通过不可翻译锚点保持在对应段落和图注位置，页面经本地图片代理展示完整图文译文；阅读页显示队列位置、真实完成分段、阶段和百分比，失败可重试，服务重启后从数据盘中间结果继续；文章和论文翻译中间文件统一存入知序数据盘并在成功后删除。
- 图文翻译会在分段前拆除 `<figure>` 外壳，把图片锚点与可翻译图注转换为普通语义段落，避免整块图片被正文分段器遗漏；格式升级时旧断点会自动失效并重新生成。
- 数学公式显示：翻译前先用不可改写锚点保护 LaTeX 源码，英文原文、中文译文和双语对照再统一使用本机 KaTeX 渲染 `$...$`、`$$...$$`、`\\(...\\)` 与 `\\[...\\]`；公式脚本、样式和字体均从本地服务提供，代码块不会被误处理。
- 学习与资料统计：作为刷新后默认首页并位于文档库之前，可切换最近 7、30、90 天和 1 年；展示活跃阅读时长、阅读内容数、活跃天数、新增资料数、阅读时长折线、阅读进度环形分布，以及可直接继续打开的最近阅读和最近入库列表。资料库内容统计使用分层横向条形图：论文库单独统计篇数，文档库按一级目录汇总全部后代、按二级目录缩进展示，并区分文档与网页文章数量；项目研读统计补充 GitHub 档案数、近 90 天仍活跃的项目、累计 Star/Fork、主要语言分布与最近研读入口。既有阅读状态用于回溯历史进度和时间节点；精确阅读时长从功能启用后，通过可见页面、近期交互与幂等阅读会话累计，不伪造历史时长。统计页整体改为低饱和薄荷色、圆角纸张层次和更清晰的图表留白。

“专题”和“卡片复习”入口目前隐藏，数据结构和代码仍保留。

## 外部网络规则

外部网页和论文请求必须通过 `EnvHttpProxyAgent` 读取 `HTTP_PROXY`、`HTTPS_PROXY` 和 `NO_PROXY`。当前电脑代理地址为本机代理，Node 原生 `fetch` 不会自动读取这些变量，因此不能直接用于外部资源。

抓取器保留 Node 默认根证书，并补充 Let’s Encrypt 官方 Generation Y 中间链，兼容漏发 YR1 链的网站；HTTPS 主机名、有效期和签名校验不会关闭。

公网 URL 安全校验会对 `ENOTFOUND`、`EAI_AGAIN` 和 DNS 超时执行有限重试；持续失败时返回中文提示，同时仍拒绝本机、私网和保留地址。

普通网页按解压后的 HTML 计算容量，硬上限为 15 MB，以兼容 Jupyter/Quarto 导出的长篇代码与公式教程；超过上限仍会在进入 DOM 解析前拒绝。

Notebook/Quarto 中合法的 Base64 PNG、JPEG、GIF、WebP 会先校验文件签名和 12 MB 单图上限，再按内容哈希写入 D 盘文章图片缓存；SQLite 正文只保存受控虚拟地址，阅读页与译文继续通过本地图片代理加载。

论文 PDF 导入采用异步流程：先保存论文记录，再在后台下载、解析、分类并唤醒 Codex 翻译。失败原因写入 SQLite，论文卡片提供重试入口。

## 开发与验证约定

- UI/文字/样式小改：运行 `node --check public/app.js` 和相关页面定向检查。
- 导入与解析：运行 `npm run test:import`。
- 数据库和持久化：运行 `npm run test:database`。
- 页面/API 集成：运行 `npm run test:ui`。
- 浏览器收藏和后台任务：运行 `npm run test:browser`。
- 视频链接、字幕解析和确认流程：运行 `npm run test:video`。
- 视频图文 PDF：除自动化测试外，使用真实视频完成端到端生成，并用 Poppler 渲染全部页面检查版面。
- 版本阶段完成或高风险修改：运行 `npm test` 全量测试。

本地静态资源使用 `Cache-Control: no-store`，修改后普通刷新即可，不再依赖手工版本号解决缓存混用。

## 视频隐私与本机资产

- 不读取、导出或保存浏览器 Cookie；登录态只用于用户在浏览器中人工确认页面状态。
- 视频入口点击后会再次说明并确认临时媒体处理；成功、失败和服务异常重启后都会删除临时视频、音频、截图及未入库 PDF。

- 最终图文 PDF 存入文档附件目录并建立 SQLite 文档、分类、文件夹和全文检索记录，不在视频暂存目录保留重复副本。
