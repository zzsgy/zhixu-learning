# 知序电脑本地版

知序电脑本地版以 SQLite 作为主数据库，原始文档、提取正文、分类结果、全文索引和备份都保存在当前电脑。只有启用 DeepSeek 辅助分类或未来的 AI 追问时，相关文本才会发送给 DeepSeek。

## 第一次运行

1. 安装 Node.js 22.13 或更高版本。
2. 在本目录执行 `npm install`。
3. 双击 `start-zhixu.bat`。
4. 浏览器会自动打开 `http://127.0.0.1:47821`。

如果需要 DeepSeek 辅助分类：

1. 复制 `.env.example` 并命名为 `.env.local`。
2. 在 `.env.local` 的 `DEEPSEEK_API_KEY=` 后填写密钥。
3. 重新启动本地程序。

`.env.local` 已被 Git 忽略，不会提交到代码仓库。

## 本地数据位置

- `data/zhixu.db`：SQLite 主数据库。
- `data/attachments/`：上传的原始文件。
- `data/article-images/`：网页文章图片的本地缓存。
- `data/papers/`：已选论文的公开 PDF 本地缓存。
- `data/backups/`：每日 SQLite 备份，默认保留30天。

备份整个知识库时，请复制完整的 `data` 文件夹。不要只复制数据库而遗漏附件。

## 支持格式

- PDF：提取文本型 PDF 正文；扫描版 PDF 后续可增加 OCR。
- Word：DOCX。
- Excel：XLSX。
- PowerPoint：PPTX。
- 文本：TXT、Markdown、HTML、JSON、CSV、XML、YAML、SQL及常见代码文件。

旧版 DOC、XLS、PPT 和纯扫描图片需要转换为新格式，或者在后续版本加入 OCR/Office 转换组件。

## 自动分类

允许的一级分类为：

- AI
- 数据库
- 安全
- 程序
- 生物工程
- 工艺工程
- 其它

系统先执行本地关键词评分；配置 DeepSeek 后，会把文件名和最多约12000字符的正文节选发送给 DeepSeek校正分类。阅读页可随时手动修改分类。

## 每周论文库

- 程序启动时检查当前自然周是否已经准备候选论文，运行期间每六小时再次检查。
- 网页打开期间每小时检查一次提醒状态；本周尚未选择时会弹出候选窗口。
- 候选论文来自 arXiv 公开索引，覆盖 AI、生物工程、工艺工程和数据库。
- 原始英文标题和摘要完整保留；页面优先展示 Codex 生成的中文标题与中文摘要。
- 论文卡片把“中文阅读”“arXiv/论文原文”和“英文 PDF”分成独立入口。
- 用户选定论文后，服务在后台缓存公开 PDF 并提取英文全文；Codex 每天早上检查标题摘要与全文翻译队列，结果写回 SQLite，不调用第三方翻译服务。
- 中文全文采用站内独立阅读页，保留方法、公式、实验、结论和附录，不设最高字数限制。
- “同步李沐精读”会从 `mli/paper-reading` 公开目录导入已录制条目，并把论文链接、Bilibili/YouTube 视频、时长和中文阅读提示保存在本地。
- 论文库可按“每周精选”和“李沐精读”筛选。
- 自动弹出选择窗口前，会等待本周候选完成 Codex 中文翻译。
- 选择“明天再提醒”会延后24小时；选择“本周不选”后，下个自然周再提醒。
- 每周最多正式选入一篇论文，只有确认选择的论文会保存进本地 SQLite。
- 候选元数据更新需要联网；网络不可用不会影响文档库和已有论文的本地阅读。
- 每日 Codex 翻译任务需要电脑保持开机，并让 Codex 桌面应用处于运行状态。

## 从云端迁移

当前本地版不会自动删除或修改原 Cloudflare D1 数据。先从原网站导出完整 JSON，保留为迁移备份。下一阶段可以根据该 JSON 的实际结构导入本地 SQLite，完成卡片、文章、批注和专题的迁移。

## 安全说明

- 服务默认只监听 `127.0.0.1`，同一局域网中的其它设备也不能直接访问。
- 上传容量默认每个文件最大200MB，可在 `.env.local` 调整。
- 不要将 `data/` 或 `.env.local` 提交到 GitHub。
- 电脑磁盘损坏仍可能造成主库和同盘备份同时丢失，建议定期把 `data/backups` 和 `data/attachments` 复制到另一块磁盘。
