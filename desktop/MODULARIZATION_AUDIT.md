# 知序模块化收尾审计

审计日期：2026-09-16

## 结论

本轮约定的结构优化、整体差异审查和正式运行验收已经全部完成，到此停止继续拆分。后台导入任务形成仓储与管理路由垂直切片，前端 AI 中心也已从主应用迁出；不再以缩短文件为目标机械调整代码。

文档上传、浏览器捕获、论文导入/翻译/导出、永久删除、文件清理和备份恢复继续保持完整事务边界，除非未来有明确功能需求和独立验收方案。提交或推送仍需单独确认。

## 后台导入任务垂直切片（已完成）

- `lib/db/stores/import-jobs.mjs` 已接管任务创建、读取、列表、原子领取、进度、成功、失败、延迟重试、下一次唤醒、重启恢复、人工重试和视频确认；`lib/database.mjs` 保持全部原命名导出。
- `lib/http/routes/import-job-routes.mjs` 已接管列表、详情、重试和视频确认四个管理接口；具体执行器、OCR、视频、论文及浏览器捕获处理器仍留在原服务编排层。
- 新增 5 个纯内存仓储测试和 4 个纯依赖注入路由测试；旧的 429/503 退避、重启续跑、浏览器令牌、arXiv 降级及完整回归均通过，当前为 277/277。

## 前端 AI 中心（已完成）

- 新增 `public/ai-center.js`，独立管理模型状态、来源筛选与最多六项选择、单资料/多资料模式、答案与引用、历史搜索与详情、阅读页选区、最近会话恢复和连续追问。
- `public/app.js` 只注入统一请求、当前阅读上下文、资料打开和工作台切换回调；后端接口、正文阅读器、统一搜索、资料批量操作、上传队列和现有 DOM 结构均未改变。
- 历史搜索、历史详情和阅读资料恢复均加入请求序列保护；切换搜索词、会话或阅读资料后，迟到的旧响应不会覆盖当前界面。阅读问答失败会恢复按钮状态并保留可操作错误信息。
- 新增 5 个模块测试，覆盖六项选择边界、多资料比较、最近会话恢复、选区传递、连续追问、引用定位、两类迟到响应和错误恢复；完整回归为 282/282。

## 本轮明确不再拆分的边界

| 范围 | 暂不拆分原因 |
| --- | --- |
| 文档上传与 OCR | 同时涉及附件落盘、数据库提交、目录归档、OCR 入队、失败补偿和备份警告。 |
| 浏览器配对与网页捕获 | 涉及 Origin 校验、令牌摘要、权限撤销、临时 HTML、同步/异步捕获和扩展专用响应头。 |
| 论文导入、翻译与导出 | 涉及稳定身份、PDF 缓存、结构校验、后台工作器、重试额度和多种导出资产。 |
| 单项/批量永久删除 | 同一事务清理阅读、标签、专题、目录、卡片、AI 会话、全文索引和主记录，并持久化待删除文件任务。 |
| 文件清理和备份恢复 | 跨 SQLite 快照、原始附件、路径边界、清单哈希和失败恢复，错误拆分可能破坏可恢复性。 |
| 文档/PDF 阅读器 | 当前包含分页、章节、结构化 PDF、图表区域、目录、进度和主题联动，需单独的浏览器验收项目。 |

## 停止条件与后续验收

本轮模块化已经达到以下源码与测试停止条件：

- 用户功能域已有清晰仓储或服务端路由边界；
- 高风险跨资源事务仍集中维护；
- 主入口主要承担装配、共享基础设施和不可分割的业务事务；
- 所有新增模块有专项测试；
- 数据库与完整回归均已通过核验。

整体差异审查与正式运行验收已经完成：24 个生产模块均已装配，数据库命名导出保持 145/145，服务端 API 路径集合保持 65/65，17 个只读运行接口和真实浏览器页面通过验收，最终完整回归为 282/282。验收发现并修复了每日经典候选在启动时刷新历史翻译时间的问题，唯一受影响记录已依据验收前快照精确恢复；修复后正式库与快照的 41 张表逐表一致。当前正式进程 PID 39220 健康运行，最终手工快照已经校验通过，三条翻译队列均为空。若没有新功能需求，不再继续结构拆分。
