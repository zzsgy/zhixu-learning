# 知序快速收藏扩展

这是知序第五批功能的本地 Chrome/Edge Manifest V3 扩展，不连接远程服务器。

## 本地安装

1. 保持知序服务运行并打开“本地数据”页面。
2. 在 Chrome 或 Edge 的扩展管理页面启用“开发者模式”。
3. 选择“加载已解压的扩展”，指向本目录 `desktop/browser-extension`。
4. 在知序页面生成六位配对码，在扩展弹窗中输入。

配对令牌只保存在扩展本地存储中；知序数据库仅保存其 SHA-256 摘要。可以在“本地数据”页面撤销任一浏览器客户端。

收藏当前网页时，扩展会在用户点击后读取当前标签页的 HTML 并交给本机知序清洗、解析。这样可以保存已在浏览器中正常打开、但拒绝后台抓取的公开文章；扩展不会读取 Cookie、密码或浏览器存储。
