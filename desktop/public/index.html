PAPER INBOX

把经典论文和自己的研究资料放进论文库。

可上传本地 PDF，也可粘贴 arXiv、论文 PDF 或公开论文网页链接。英文论文会保留原文，并进入 Codex 中文翻译流程。

公开 PDF 会缓存到本机；普通论文网页会保存可读取的标题、摘要和正文。

ARTICLE INBOX

也可以粘贴链接，保存公开网页正文。

输入普通网页或微信公众号文章链接。知序会提取正文、过滤脚本， 生成简介并自动归入对应技术领域。

支持 Docsify 根链接和公开 GitHub docs 目录；会先展示章节预览，再按顺序批量导入。

VIDEO INBOX

粘贴视频链接，把字幕、讲解和关键画面变成可检索资料。

支持 YouTube 和哔哩哔哩公开视频。知序只读取元数据与公开字幕； 没有独立字幕轨时会停下来询问，可选择本地转写并生成包含 PPT 关键画面的 PDF。

默认不下载媒体。只有明确确认生成图文 PDF 后，才临时处理视频和音频；完成后自动删除临时媒体。
